# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Original vanilla JavaScript/CSS userscript, build-time bundled owned exp-core. No remote runtime dependencies. Public repository: https://github.com/ExtraPotions/Thread, with built userscript assets.

## Users

Readers using modern desktop Reddit feeds and discussions, including keyboard and narrow-window users.

## Product Purpose

Reading, reversible local filtering and personal context alongside native Reddit. Product name and suite header Thread. Sole authorship expDARE.

## Operating Context

The approved native-style preview establishes visual direction. Native desktop account components and feed wrappers have now been observed read-only; the local candidate is checked on authored fixtures shaped from that structure. Installed candidate compatibility, Reddit's live shadow rendering, mobile web and long sessions remain unverified.

## Capabilities and Constraints

Four content views (Cards, Compact Cards, Grid, List), feed defaults, native sort destinations, independent sidebars, bounded visible native loading, local rules/tags/notes, comment traversal/context/collapse/read exposure, on-demand first-party images and shared Core menu/launcher. Basic account identity uses native DOM without API calls. API enrichment is unavailable until legitimate independently registered access exists. Account switching remains deferred. Code, including owned Core, uses PolyForm Noncommercial 1.0.0; original artwork and documentation use CC BY-NC-SA 4.0. User release/commit/push authorization and publication resumption were confirmed on 2026-10-20. Installed copies are updated separately.

## Brand Commitments

Selected T1 Asscher orange gem, owned SVG geometry and facets with no pictogram or letters. The earlier Pear Crystal shape is superseded; the existing warm facet-color palette remains available as an optional gem menu theme, off by default. Native/site-aware palette remains default. Only THREAD menus and notices receive gem colors; page content and other products retain their own appearance.

## Product Principles

- Reading stays on the native page.
- Local annotations stay separate from native account writes.
- Every treatment has a reveal; every hidden sidebar has a restore.
- Bounded work, isolated regex and disposable route state.
- Report unavailable controls, enrichment and verification limits truthfully.

## Accessibility & Inclusion

Rectangular switches, rounded rectangular controls, visible focus, readable content type, narrow containment, remappable shortcuts that ignore editors/composition/native modals, keyboard media controls and focus restoration.
