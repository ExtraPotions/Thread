# Thread local development

Menu trim (0.2.3): the menu keeps about 17 controls. `RC.Model.settings` applies a frozen `fixed` object for settings without a control (stored values for them are ignored) and `combined()` ties grouped keys to the one control that drives them (for example `rememberSort` → `rememberCommentSort`, `navButtons` → `keyboard`, `hideDecorations` → flair/awards/author/save visibility, and Read posts → `trackPosts`/`hideReadPosts`). Community filters are exact `community` rules (`exact:true`) written by `setCommunityFilter`, within the 100-rule cap and only for a recognized account. Unblur clicks the shadow `.overlay button` of `shreddit-blurred-container[blurred]` once per container; `reason=nsfw` also requires a recognized account. The right-rail handle is shown only where Reddit displays `#right-sidebar-container`; collapsing sets `data-rc-fill` on its `.main-container` parent (one `minmax(0,1fr)` column, border-box, 40px end padding). Tests: `tests/menu-trim.test.cjs`. Compact rows: on Reddit's current card shadow (title column beside a `slot[name=thumbnail]` column, then the action row holding `slot[name=share-button]`), `compactRow` adds one shadow style from 600px: the thumbnail column takes `margin-bottom:-40px` and the action row reserves 112px at its end, so vote/comments/share sit beside the 104×78 thumbnail (live rows 159→119px). Below 600px the row stays full width. This supersedes the 0.2.1 full-width compact footer on tablets. Tests: `tests/compact-row.test.cjs`.

Fluid feed pass: Grid is span-based masonry. Each visible child of the grid container (posts, `shreddit-ad-post`, other non-empty native modules) is one `data-rc-view-wrapper` cell spanning `ceil((height+12)/4)` 4px rows, kept current by one ResizeObserver; zero-height native children (`faceplate-loader`/partials) get `data-rc-view-aux` and sit absolutely at the grid's end so their visibility still requests the next page. Feed ads follow the view through Reddit's own `view-type` (compactView in Compact, cardView otherwise) plus `data-rc-view` for the shared frame, and are restored when Native is chosen or Thread is released. Media inside a native `[data-aspect-ratio-container]` frame is excluded from the uncapped-media rules, so Cards and Grid keep Reddit's whole-image letterbox and rounded clip. The touch actions panel is a vertical menu (7px radius, `0 4px 10px #0003`, 40px rows, 44px on coarse pointers). Motion: the menu fades and settles 4px on entry (`@starting-style`, 140ms exponential ease-out), opened compact media fades in, and a chosen view fades the feed from 35% opacity over 180ms with WAAPI; nothing blocks input, and all of it is off under `prefers-reduced-motion: reduce`. The View Transitions API was tried and rejected because hit tests land on the document element for the whole transition. The popover's `overlay`/`display` discrete transitions were also rejected: Chromium kept the panel out of the top layer at transition start, so fixed positioning resolved against a transformed ancestor.

Touch feed actions: the trigger is a square icon sized to the native footer buttons (32px fallback) with a visually hidden Thread actions label; the launcher gem is unchanged. Shadow posts get an owned named slot appended to the right-aligned group of the native action row (`rpl-action-bar [data-testid=action-row]`, else the overflow-menu-bar slot's parent); Grid tightens that row's gap to 6px so the icon fits 296px cards; rows holding the slot may wrap, so crowded rows (repost, moderator actions) put the right-aligned group on a second line instead of clipping it. Posts without a shadow action row append the icon to the post. Native nodes are not moved. Reddit's global `details` padding/margin/background is reset on the trigger. Compact media previews use the native preview.redd.it rendition with eager loading (lazy images in the slotted preview never started loading on live Reddit). Actions use a manual HTML popover where supported, with fixed-position fallback; native header clipping/transform cannot clip the top-layer menu. Escape/outside click, local-overlay suspension/restoration, focus and resize placement are covered. Collapsed/hidden recovery controls remain separately projected and accessible. Compact native thumbnails remain80x60. The original previous-build32-test proof is superseded for this change; run the current suite. Actual installed iPad Safari/live native menu packing remain unverified.

## Native DOM contracts and evidence

Identity does not require a profile drawer to be open. `src/adapter.js` reads `shreddit-app` identity attributes, native `achievements-entrypoint[username]` / `after-login-toast-dispatcher[username]`, and canonical `/user/<name>/` links within the header or user menu. It excludes owned controls and post/comment descendants, normalizes names, and accepts a single distinct valid name. Conflicting names return unknown identity and pause private records. A native login link can identify the guest scope when no account name exists. These are DOM observations, with no identity API request or account-switch action.

The original flat feed fixture did not represent native article wrappers with direct `hr` separators or the `shreddit-post` `view-type` contract. The current runtime marks compatible grid wrappers, hides only direct `hr` children of the marked grid container, and leaves other unmarked children spanning the grid. Native renderer choice follows the supplied light-DOM media slots: compact expandos retain `compactView`, card media retains `cardView`, and posts without either keep their known native renderer. Thread layout changes do not swap away the slot required by the existing player. Returning to Native or releasing a post restores the saved native attribute only while it still equals Thread's applied value; a later site-owned value is preserved. This describes the local implementation, not acceptance of Reddit's actual shadow rendering.

On feeds whose `main` holds `shreddit-async-loader[bundlename=shreddit_sort_dropdown]`, the feed controls (`.rc-pagebar[data-rc-inline]`) mount as the loader's next sibling inside its row (`data-rc-sort-row`, flex-wrap), styled as 32px plain buttons; the native loader's children are never touched, and a re-rendered row is re-joined on the next scan. Without that loader (comment pages, fixtures, old layouts) the strip stays first in `main`, in normal document flow, leaving native Sort By controls unobscured. It contains the view selector (a restyled native `select` with authored sliders/chevron icons) plus configured destinations/sort/loading controls. Previous/Next and “Jump between loaded comments” belong to comment pages. Jump scope selects navigation targets; it does not filter visible comments or search unloaded replies. Back to top is a separate fixed action, shown after scrolling. Persistent and temporary sidebar controls live in Feed → Sidebars.

`tests/browser.cjs` has authored cases for native component identity/conflicts, wrapped feed separators and native attribute restoration, comment-only jump scope, the non-sticky feed strip, separate top action and Feed sidebar controls. The prior `local-verification/thread-refinement-20261020/browser-final.log` records 35 passing browser groups with no page errors; that is retained fixture evidence, not a test run performed by this documentation pass or proof for the current release candidate. Native feed-action visibility and parent-preview findings remain outside this change. Installed Vivaldi, touch, screen-reader and long-session acceptance remain unverified. Account switching remains deferred.

## Local runtime and distribution

Storage bounds: 100 rules, 1,000 people with explicit capacity failure, 100 thread visits × 500 read IDs, 100 collapse records × 500 IDs, up to500 hidden-history records, 20 pinned native destinations. User-authored people records do not expire silently; history/visits expire under the configured retention. No post bodies/media are stored. At most250 nearby content nodes and250 exposure timers are retained; regex batches are sequential, at most250 texts ×4,000 characters, patterns256 characters and90ms wall-clock deadline. A page scan examines at most2,000 candidate nodes. Automatic loading starts off and caps each content type at1–5 visible native batches per route; manual retry cannot reset its budget. Route changes cancel work and clear transient node references.

Native account identity is read only from narrowly identified header/app surfaces; unknown identity pauses private rules, people and reading/history records. There is no credential access or account switching. Separate tabs re-read current data before record updates and receive userscript storage listeners. Import/export is deliberate and validated; diagnostics omit usernames, page text, URLs, personal records and credentials.

The opener uses Core's existing SITE_SLOTS machinery. On www/sh Reddit, only while a Thread launcher is registered, Core derives a slot from the native left rail and accessible collapse/expand handle. The circular shared gem matches the smaller native handle dimension (24–48px, normally32px), straddles the rail edge and sits8px below the handle; menus dock beside it, or below at narrow widths. Missing/collapsed rails use a top-left fallback below the native header/handle. Resize, bounded page-mutation invalidation and scrolling recalculate geometry; replacing a rail releases the previous size observation. Reddit flyouts update their slot when the rail changes rather than freezing stale geometry. No native control is repurposed and no extra in-page anchor/launcher is inserted. Other sites and Reddit without Thread retain their existing placement. Version notices use Core's theme-bearing notice controller, with no fictitious release/install links.

Thread uses native page data and local records; it has no Reddit API integration or API access controls. Karma/account-age enrichment and resolved nicknames are not supported. Native video remains native; companion viewer currently covers first-party images only. The local bookmark library is described below; offline content snapshots are not implemented.

Publish release uploads the selected committed userscript, gem and SHA256SUMS without rebuilding or testing. Manual tests check out matching Core beside Thread; Windows uses the approved shell and Linux uses the default Playwright headless shell. Prepare future patches with RELEASE_NOTES_JSON and npm run prepare:release:feature, then build and verify. Publication does not establish installed acceptance. The shared header heart uses the suite donation control.
