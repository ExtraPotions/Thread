## 0.1.0 — 2026-10-20

- Adds Cards, Compact Cards, Grid and List layouts, native sorting and sidebar controls for modern Reddit.
- Offers reversible local filters, private author tags and notes, and navigation through loaded comments.
- Detects the current account from native Reddit components without an API request for basic tools.
- Uses the shared compact ExtraPotions menu, orange Asscher gem and optional warm gem theme.
